## 🌟 Overview

**Egyptian Landmarks App** is a feature-packed mobile application designed to help users discover, explore, and navigate Egypt's rich historical and cultural heritage.

Built with **Flutter**, the application combines a modern user interface with AI-powered capabilities, including an interactive chatbot trained on custom Egyptian tourism data and image-based landmark recognition.

The app aims to make exploring Egypt's historical landmarks more accessible, informative, and engaging.

---

## ✨ Key Features

* 🤖 **AI-Powered Tour Guide & Chatbot:** An interactive chatbot trained on custom Egyptian tourism data to provide recommendations and historical information.
* 📷 **Image-Based Landmark Identification:** Identify monuments and landmarks using images captured or uploaded by users.
* 🗺️ **Interactive Maps & Navigation:** Explore landmarks geographically and discover nearby attractions.
* 🔍 **Advanced Search & Smart Filtering:** Find landmarks by category, city, popularity, or user rating.
* ⭐ **Ratings, Reviews & Community:** Share feedback, rate visited places, and explore user reviews.
* 🎨 **Dynamic Theme Support:** Switch between Light and Dark themes.
* 📱 **Responsive UI:** A user-friendly Flutter interface designed for different mobile screen sizes.
* 🏗️ **Clean Architecture:** Organized application layers and state management using Bloc/Cubit.

## 🚀 Getting Started

### Prerequisites

* Flutter SDK
* Dart SDK
* Android Studio or Visual Studio Code
* An Android emulator or physical device

### Installation

**1. Clone the repository**

```bash
git clone https://github.com/AbdullahMohammedAtta/EgyptLandMarks
```

**2. Navigate to the project directory**

```bash
cd Egyptian-Landmarks
```

**3. Install dependencies**

```bash
flutter pub get
```

**4. Run the application**

```bash
flutter run
```

> Configure any required API keys, Firebase settings, and backend services before running the application.
