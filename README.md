## 🌟 Overview

**Egyptian Landmarks App** is a feature-packed mobile application aimed at discovering, exploring, and navigating Egypt's rich historical and cultural heritage. Built with **Flutter**, the app blends modern UI/UX with cutting-edge **AI capabilities**, including an interactive chatbot trained on custom Egyptian tourism data and real-time landmark recognition via computer vision.

---

## ✨ Key Features

- **🤖 AI-Powered Tour Guide & Chatbot:** Integrated chatbot trained on custom Egyptian tourism datasets to provide instant recommendations and historical context.
- **📷 Image-Based Landmark Identification:** Users can take or upload photos of monuments/landmarks to identify them instantly using computer vision models.
- **🗺️ Interactive Maps & Navigation:** Map integration showcasing nearby attractions, historical routes, and geographical details.
- **🔍 Advanced Search & Smart Filtering:** Quickly find landmarks by category, city, popularity, or user rating.
- **⭐ Ratings, Reviews & Community:** Users can share feedback, read authentic tourist reviews, and rate visited spots.
- **🎨 Dynamic Theme Support:** Seamless switching between Light and Dark themes according to user preference.
- **📱 Clean & Responsive UI:** Designed following Clean Architecture principles for smooth animations and consistent responsive design across mobile screens.
